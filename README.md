## 快速使用

直接用浏览器打开 `index.html` 即可（无需服务器）。页面为纯前端静态应用，数据集中存储在 `js/data.js`，图表渲染由 `js/app.js`（ECharts）驱动。

## 数据说明与溯源

本看板强调**数据可追溯、缺失如实标注**，主要来源：

- **黄金**：世界黄金协会（WGC）《全球黄金需求趋势报告》——央行购金、需求结构、ETF 持仓、矿产金产量
- **铜**：国际铜研究组织（ICSG）——精炼铜产量、消费量；LME/SHFE/COMEX——库存与价格；上海钢联——加工费 TC
- **宏观**：ICE（DXY）、FRED/美国财政部（TIPS 实际利率）、标普全球/JP摩根（全球 PMI）

> 数据口径说明：年度均值为市场综合口径，部分系列（如黄金库存、年度均价）为公开数据整理的参考值/估算值，已在 `data.js` 对应字段的 `note` 中如实标注；未搜到权威数据的指标均以「参考」「估算」标注，**不做编造填充**。

## 技术栈

2. 定期（如每周）用权威机构最新报告刷新数据与 `meta.updated` 日期
